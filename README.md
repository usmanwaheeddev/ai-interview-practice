Foundation for an AI-powered hiring and interview platform.

```text
ai-hiring-interview/
```

## Status

This initial commit establishes the repository structure only. Application
implementation, setup instructions, and tests will be added in subsequent commits.

## Configuration and privacy

Keep credentials, environment files, interview recordings, resumes, and other
candidate data out of version control. Future configuration examples must use
placeholder values only.
